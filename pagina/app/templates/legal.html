Descripción

{{ app_name }} es un prototipo académico de soporte a la decisión clínica, desarrollado como Proyecto Integrador de Ingeniería Biomédica (UNC). Utiliza un único modelo de detección, {{ modelo }} (YOLOv8m, una sola clase: «fractura»), que señala mediante cajas delimitadoras las regiones compatibles con fractura en radiografías de muñeca pediátrica.

Cada proyección se analiza por separado: el modelo no combina las vistas entre sí. En un estudio de varias imágenes, el nivel de prioridad del estudio corresponde al de su proyección de mayor prioridad. {% if clahe %}Antes del análisis, cada imagen se preprocesa con CLAHE (límite {{ coma(clahe.clip, 1) }}, grilla {{ clahe.grilla }}×{{ clahe.grilla }}), igual que en el entrenamiento.{% endif %}

El resultado puede descargarse como informe PDF. No existe una API pública: el sistema se utiliza únicamente desde esta interfaz, con sesión iniciada.

No emite diagnósticos. Todo resultado debe ser interpretado, validado y aprobado por un médico matriculado.

Limitaciones conocidas

  • Dominio acotado. El modelo se entrenó con GRAZPEDWRI-DX, con partición por paciente: radiografías de muñeca de pacientes de 0 a 19 años. Fuera de esa región y de ese rango etario su comportamiento no está validado. Los análisis realizados con un modelo anterior que permanezcan en la base se muestran marcados como «modelo anterior», sin prioridad clínica, y no se incluyen en las métricas.
  • El puntaje del detector no es una probabilidad. El número que acompaña a cada caja delimitadora (rotulado «Seguridad») es el puntaje de confianza del detector posterior a la supresión de no máximos (NMS): permite ordenar las detecciones, pero no es una probabilidad de fractura. El modelo no se calibró, por lo que ese número no debe interpretarse como tal.
  • Los umbrales son operativos. Con un puntaje igual o superior a {{ coma(umbrales.hallazgo) }} (umbral de clasificación) la imagen se clasifica con hallazgos («Revisar»); ese umbral se eligió sobre la partición de validación. Con {{ coma(umbrales.prioritario) }} o más se clasifica como «Prioritario». Entre {{ coma(umbrales.caja) }} (umbral de visualización) y {{ coma(umbrales.hallazgo) }} la región se dibuja con una caja delimitadora punteada («Límite»), sin clasificar la imagen como anormal. Los umbrales ordenan la revisión; no reemplazan el criterio clínico.
  • Un negativo no descarta fractura. {% if meta and meta.sensibilidad is not none %} En el test interno, con el umbral de clasificación de {{ coma(umbrales.hallazgo) }}, no se clasificaron con hallazgos {{ miles(meta.test_FN) }} de las {{ miles(meta.test_n_positivos) }} radiografías con fractura (sensibilidad por imagen {{ pct(meta.sensibilidad) }}): alrededor de {{ ((1 - meta.sensibilidad) * 100)|round|int }} de cada 100 radiografías con fractura no fueron señaladas. {% else %} El modelo en uso no tiene métricas publicadas en este sistema, por lo que esta página no informa ninguna tasa de detección. {% endif %} Por ello, un resultado sin hallazgos nunca se presenta como un resultado normal confirmado.

Datos de los estudios

Las imágenes DICOM se convierten a PNG sin sus metadatos (los datos del paciente no se usan ni se guardan), y cada imagen se guarda con un nombre aleatorio. En los estudios ZIP, los nombres de las imágenes se guardan con las secuencias numéricas largas ocultas; el nombre del ZIP se conserva tal como se cargó. Cada usuario accede únicamente a sus propios estudios. El informe PDF incluye las imágenes: una vez descargado, queda fuera del control del sistema.

Se trata de una instalación de demostración con fines académicos: no debe utilizarse con estudios de pacientes identificables.
